# AI-Image-Recognition
AI-powered image recognition system for automated quality control, using deep learning and computer vision to detect product defects, classify quality, and generate inspection reports through an interactive dashboard.

## AI-Powered Quality Control System
Automated visual defect detection for industrial casting parts using MobileNetV2 and Streamlit.

### Setup Instructions
1. Install required packages:
   pip install -r requirements.txt

2. Run the application:
   streamlit run App.py

3. Open http://localhost:8501 in your browser and upload test images from `sample_images/`.
